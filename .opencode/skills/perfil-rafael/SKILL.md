# Rafael Vieira profile

Read the full document at [`perfil-rafael-vieira.md`](../../perfil-rafael-vieira.md) when:

- the task involves prioritization, scope, or "what to build now";
- tone should reflect ambition with sustainability (not speed alone);
- risk of opening more fronts without closing cycles.

Summary for the assistant:

- **Archetype:** Builder + Strategist + Silent competitor (existential, not performative).
- **Strength:** systems, product, impact, learning by building.
- **Risk:** scatter, self-pressure, overload under stress — not laziness.
- **Professional profile:** Product Engineer / Tech Lead / technical Founder.
- **Calibration:** consolidate and use tools (e.g. Vieira CLI); close proposal → implemented → real use.

Complements always-on rule `writing-style-rafael.mdc`. Do not use as clinical diagnosis or therapy substitute.

## Not this file

For **operational** questions about Rafael as a developer — which repos he works in, which features he owns, which cards he delivered — read `.perfils/RafaelHDSV.md` instead.
