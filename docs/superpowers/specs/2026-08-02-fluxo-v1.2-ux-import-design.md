Polir a UX diária, tornar a **Importação** o ritual mensal de entrada de dados (OFX Santander), reorganizar **Categorias/Orçamentos** e **Investimentos** (ex-Metas), enriquecer Wishlist com imagens, melhorar relatórios e **desvincular Notion** do produto (ficou só como carga inicial histórica).

## 3. Escopo por área

### 3.1 Marca e shell
- Novo `logo.svg` / favicon: “F” fluido + seta, alinhado a DESIGN.md (menos elementos competindo)
- Sidebar **fixa** (`sticky`/`fixed`): scroll só no `<main>`
- Ícones Lucide em todos os links da sidebar (e mobile “Mais”)
- Label **Dashboard** (não Painel)
- Modal de confirmação ao **Sair**

### 3.2 Datepicker e confirmações
- Substituir `input type="date"` cru por componente de data pt-BR (display DD/MM/YYYY, valor ISO interno) — Popover + calendário ou padrão shadcn-like
- Modal de confirmação para: excluir transação/conta/investimento/wishlist/orçamento, sair, e editar destrutiva quando aplicável

### 3.3 Dashboard
- Filtro de período: **mês** | **ano** | **todo** (default: mês corrente)
- KPIs e gráficos respeitam o filtro
- Corrigir gráfico Receita×Despesa: `grid.top` maior / legend fora da área das barras (evitar sobreposição)
- Trocar “Evolução do saldo” → **Resultado acumulado no período** (série diária do filtro)
- Manter donut de categorias no período

### 3.4 Transações
- Filtro mês / ano / todo (+ busca, tipo, etc.)
- Agrupamento visual por mês na listagem
- Receita: sem checkbox **Pago**; sem coluna **Meio** na tabela (meio só para despesa)
- Ações Editar/Excluir → ícones (Pencil / Trash) + confirmação no delete
- Datepicker melhorado no formulário

### 3.5 A pagar
- Filtros: **mês atual** | **qualquer mês** (seletor) | **todo**
- Total e badge coerentes com o filtro

### 3.6 Importação (entrada mensal)
- Copy/UX: “Todo início de mês: baixe o OFX no Santander (Money 2000+) e importe aqui”
- Passos curtos na UI + preview + commit com:
  - dedupe
  - sugestão de categoria via regras
  - mapeamento conta destino
- Manter CSV/OFX genérico; destacar preset Santander
- Remover ênfase Notion da tela e docs de produto

### 3.7 Contas
- Só contas/cartões (CRUD + ícones)
- Remover Categorias e Regras desta tela

### 3.8 Orçamentos (categorias + metas de gasto + regras)
- Listar **todas** as categorias com:
  - gasto **mensal** (mês corrente ou selecionado)
  - gasto **anual**
  - gasto **todo** (histórico)
  - **meta de gasto** (`fluxo_budgets` mensal; garantir linha/default para cada categoria de despesa)
- CRUD categoria + ícone/cor
- Seção **Regras de categorização** (explicação em uma frase + CRUD)

### 3.9 Investimentos (ex-Metas / `fluxo_goals`)
- Nav e páginas: **Investimentos**
- Conceito: caixinhas (reserva emergência, viagem Chile…) com alvo, valor guardado, progresso, conta opcional
- Rotas: `/investments` (redirect `/goals` → `/investments`)

### 3.10 Wishlist + imagens
- Coluna `image_url` (migration)
- Reimport/atualização one-shot das capas Notion (URLs já conhecidas no dump Capa) quando possível
- Cards com thumbnail

### 3.11 Relatórios
- Filtros período claros (mês/ano/intervalo)
- Visão calendário já existente refinada (destaque mês corrente, empty states)
- Labels/ícones consistentes; menos enums crus
- Gráficos com mesma correção de legend/grid

### 3.12 Docs
- `docs/context.md`: Notion histórico; import OFX Santander; Investimentos; Orçamentos=categorias+regras
- Não depender de Notion para operação contínua

## 4. Arquitetura (delta)

```text
UI (sidebar fixed + DatePicker + ConfirmDialog + icons)
  → BFF
      GET /reports/dashboard?period=month|year|all&month=&year=
      GET /transactions?from&to&… (já paginado)
      GET /categories/stats?…  (gasto mês/ano/todo por categoria)
      budgets: ensure defaults / upsert por categoria
      imports: copy Santander-first
  → Postgres
      fluxo_wishlist.image_url
      (goals inalterados no schema; só UX Investimentos)
```
