# Fluxo MVP — Implementation Plan

> **For agentic workers:** seguir este plano task-by-task. Gate do `ai-development-workflow`: nenhum código de feature até aprovação explícita da proposta `.issues/` (autorizada nesta sessão por “Implement the plan”).

**Goal:** Dashboard financeiro pessoal (transações, importação CSV/OFX, orçamentos, metas, relatórios) no repo scaffold Vieira.

**Architecture:** React/Vite front → Supabase Auth (JWT) → Express BFF → Supabase Postgres com RLS; Storage para arquivos de importação; Apache ECharts no dashboard.

**Tech Stack:** React 18, Vite, TypeScript, SASS, Express 5, `pg`, Supabase Auth/Postgres/Storage, `echarts` + `echarts-for-react`, Yarn.

**Decisões fechadas:** MVP Fases 1–7; Auth Supabase e-mail/senha; Supabase completo + Express BFF; entrega por fases do épico; SASS (sem Tailwind); BRL; Open Finance fora do MVP.

**Epic:** https://github.com/RafaelHDSV/Fluxo/issues/1
