A flow **bug** already covered by an epic (e.g. restriction list) may have its **own** issue (e.g. **#7131**) — confirm the number on the board when formatting the daily.

**Card lookup (hard):** every named card/task in the draft must be resolved in this table or via GitHub search on `AGX-Software/board` **before** writing. Use the official issue title. Do **not** invent a card from a product name alone. If unresolved after search: short description, no invented `#NNNN` — then add the issue here after the board is published.
